# AURA · More than accessories

متجر إكسسوارات هاند ميد. موقع ستاتيك (HTML + CSS + JavaScript) من غير build، بيترفع على Vercel على طول.

## تعديل البيانات

| عايز تغير | الملف |
|---|---|
| رقم الواتساب، إنستا باي، فودافون كاش، الشحن، إنستجرام | `js/config.js` |
| صور الصفحة الرئيسية وقصتنا والتصميم الخاص | `js/config.js` ← `SITE_IMAGES` |
| الأقسام والمنتجات والأسعار وصورها | `js/products.js` |
| الألوان والخطوط | `css/style.css` (أول الملف) |

الصور حالياً من Unsplash (مسموح استخدامها مجاناً). عشان تحط صورك الحقيقية، حطها في `images/` واكتب مسارها مكان الـ id، مثلاً `'images/products/pearl-bag.jpg'`.

## الطلبات

- العميلة بتختار المنتجات وتكمل بياناتها في السلة، وبعدين بيظهرلها رقم الطلب والمبلغ ورقم التحويل.
- زرار واتساب بيبعت تفاصيل الطلب كاملة لرقم المتجر، والعميلة بتبعت سكرين التحويل في نفس الشات.
- الطلبات بتتحفظ على جهاز العميلة بس (مفيش سيرفر)، فصفحة "تتبع طلبي" بتشتغل من نفس الجهاز اللي اتعمل منه الطلب.

## التشغيل محلياً

```
python3 -m http.server 8000
```
وافتح http://localhost:8000
